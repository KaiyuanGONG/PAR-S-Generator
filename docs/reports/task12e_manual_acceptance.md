scale and runtime identity locked**.

passed, `cnc5`, `cnc7` and `cnc8` generated byte-identical `.a00`, `.mhd` and

they are different platform builds and produce different absolute count
scales. This remains non-blocking under the previously frozen Task 12E
contract only because Linux is now the sole production reference. Windows
engineering cases must never enter a Linux production manifest.
